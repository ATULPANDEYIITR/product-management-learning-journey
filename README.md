# Day 01: Project Management Fundamentals

## Objective

Begin building a strong foundation in Project Management by understanding what projects are, how they are managed, and the fundamental concepts involved in successful project delivery.

## Topics Covered

* What is a Project?
* Project Characteristics
* Project Objectives
* Project Constraints
* Project Stakeholders
* Role of a Project Manager
* Project Lifecycle
* Basic Project Planning
* Project Risks
* Project Success Factors

## Code Implementation

The Python program demonstrates:

* Defining a project
* Identifying project characteristics
* Understanding project constraints
* Identifying stakeholders
* Listing project manager responsibilities
* Understanding the project lifecycle
* Creating a simple project plan
* Identifying a project risk
* Identifying project success factors

**External Libraries:** None

## Why This Matters

Project Management provides the structure required to plan, execute, monitor, and successfully deliver projects while managing scope, time, cost, quality, resources, risks, and stakeholders.

## Learning Approach

Project Management will be covered gradually, starting with fundamental concepts and progressing toward project planning, scheduling, risk management, stakeholder management, Agile, Scrum, project controls, delivery management, and advanced project management concepts.
